# blastradius

blastradius takes a leaked credential and tells you how much it matters. It confirms the secret is live with a read-only check, works out what it can reach, and weighs that against real-world impact: how widely used the repos it can push to are, whether it can publish packages other software depends on, and whether the asset looks like production. It then returns a severity rating with the evidence behind it, refined by an optional AI classifier ([TypeSafe Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev)) that sees only the evidence, never the secret. It's built to run after scanners like TruffleHog and Kingfisher, which detect secrets well but do not assess the impact of a finding. Verification is handled by blastradius itself, so you can run those scanners with verification off and pass the raw findings straight in, and it checks validity and enriches in one step. It covers GitHub, GitLab, AWS, GCP, Azure, npm/PyPI, Slack, and Stripe today, with more types to follow.
